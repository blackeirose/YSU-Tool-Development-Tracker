New software tools default to GitHub = Required. Use Optional/No only when version control or deployment adds little value. Use the left checkboxes + Delete Selected for batch removal, or × for one item. Sorting rules: Status defaults to Active → Planning → Future → Idea → Paused → Complete. Priority defaults to High → Medium → Low. Click the same header again to reverse the order. Progress, Image2, and Hours sort numerically. Codex Load is a relative workload estimate: XS → S → M → L → XL, not an actual OpenAI credit amount.
